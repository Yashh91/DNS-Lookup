# DNS Lookup Tool

A simple Python command-line tool that performs DNS lookups for a given domain. It retrieves useful DNS information using Python's built-in `socket` module.

## Features

* Get IPv4 Address
* Get IPv6 Address
* Get Hostname
* Perform Reverse DNS Lookup
* Beginner-friendly code
* No external dependencies

## Requirements

* Python 3.x

## Installation

Clone the repository:

```bash
git clone https://github.com/Yashh91/DNS-Lookup.git
```

Move into the project folder:

```bash
cd DNS-Lookup
```

## Usage

Run the tool:

```bash
python dns_lookup.py
```

Example:

```text
Enter Domain (example: google.com): google.com
```

Example Output:

```text
IPv4 Address : 192.178.158.102
Hostname     : nv-in-f113.1e100.net
IPv6 Address : 2404:6800:4013:802::71
Reverse DNS  : lcdels-in-f102.1e100.net
```
